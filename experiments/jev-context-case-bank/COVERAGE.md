# 八类覆盖矩阵与题目目录

本轮是 **10 个基础题、28 个实际输入臂**，不是 28 道独立题，也不是模型跑分。

- 内置／历史分区：5 题、12 臂。其中 **3 题围绕当前科比特宅内容及历史记录**；另 **2 题明确来自通用契约夹具**，不冒充模组作者情节。
- PDF 分区：5 题、16 臂，选取血色公路中可精确绑定的段落。此前两书的 30 题广覆盖设计仍保留，不重复计作本轮的新题。
- 33 个短来源锚点均有实际文件指纹、定位器和唯一精确引文。

## 总矩阵

| 历史类别 | 具体题与实际对照 | 这一格检验什么 |
| --- | --- | --- |
| 1. 同对象不同用途 | `beetle-purpose-routing`：相同金属甲虫、情境、候选池，只改问分布／触发或问火焰反应；`chair-look-vs-swing` 是观察／挥击的契约补充 | 对象相同不等于应该取同一份材料，也不等于授权同一用法 |
| 2. 多段材料合取 | `beetle-joint-supplement`：物理71页的场景触发 + 103页的火免疫；已有零段／一段／两段 | 只拿到一段不能宣布齐全，已有部分时只补剩余事实 |
| 3. 提过不等于已经具备 | `idol-context-fidelity`：none、同页半段、完整原文、忠实改写、丢条件摘要、同版本cache-only | 保真改写说全事实但不等于原文核验；主题摘要及未供给缓存不能算当前已有材料 |
| 4. 联合去冗余 | `beetle-joint-supplement`：A、原文重复A、语义改写A、B、A+B组合包、鼠群材料同时入池 | A+B的多个充分组合可以成立；A+A不能代替A+B，已有A后也不该再追加A+B整包 |
| 5. 记忆更正与当前状态 | `ownership-withdrawal-recall`：撤回前／撤回后／撤回后迟到旧抽取 | 当前说法不能按到达顺序复活；撤回Hayes声明也不证明产权属于Knott |
| 6. 观点归因与证据方向 | `globe-evidence-direction`：支持但未证明／把支持反说成反驳／同句改说话者 | 保留真实图关系方向，区分玩家观点与记录声称的文章观点，不把来源声称当事实背书 |
| 7. 当前目的及公开／空间范围 | `newspaper-interest-vs-travel`：看看报纸／明确去剪报室；`house-outside-vs-inside`：外部巡视／明确进入；附加线索提案保持不变 | 旅行选择不等于已经获得受限资料；同一scene id不授予室内行动或日记发现 |
| 8. 源文未知与相关冲突 | `harpoon-conflict-scope`：相同原文，问人数／问牵引绳长；`idol-contradiction-versus-unsupported`：一致报告／明确互斥／无依据护甲增益 | 题外绳长矛盾不拦人数；绳长本题不能择一。无依据新增不自动构成逻辑矛盾，缺依据也不能被模型常识补齐 |

以上是**设计与输入覆盖**。有候选选择要求的题已发出真实的组合选择 Choice，返回值可映射到追加材料并评分，不再只问“是否够用”。有来源与预期，不等于 Jev 已正确回答；机械检查也不替代语义复核。

## 内置／历史题：不是凭空编的新剧情

### 报纸兴趣与明确旅行（2臂）

- 玩家话：“那看看报纸”／“我去环球报的剪报室查这栋房子的旧闻。”
- 固定同一尚未出发、未取得受限访问、未完成检索的前提，以及 move + 未刊稿 clue + time 提案。
- 前一句来自合成准入测试，后一句来自真实 `admission-e2e-1/turn-4.json`。二者原上下文不同，**本题统一前提是作者设计，不冒充历史真桌A/B**。
- 明确去处使旅行选择成立，不使未刊稿发现或计划耗时自动成为既成事实。

### 宅外巡视与入内（2臂）

- 原话：“天亮以后我先到科比特宅外面走一圈，看看房子的外观和周围街道。”
- 对照：“我先进入科比特宅的一层，看看里面的布局。”
- 第一臂来自真实 `board-map-arrival-20260919/turn-1.json`；第二臂是明确标注的设计扰动。当前图提供撬柜与日记路线，不意味着角色已发现。
- 实录中拒绝的是夹带研究线索的批次，之后 move/time 成功；不能歪写为连到宅外的选择都非法。

### Globe方向与说话者（3臂）

- 对比“报道支持这个可能，但未独自证明”与“报道反驳了科比特意志造成悲剧”。
- 文章、目标结论与 supports 关系来自当前图；历史误读来自研究报告，**本仓没有对应原turn，不能称逐字回放**。
- 第三臂把同一争议句从玩家改标为文章说话者，是有意的错误归属刺激；任务识别输入声称的归属，不替错误归属背书。
- 关系行本来就是生产提供的数据，因此可进输入。本题检查使用关系是否反向，不冒充仅凭新闻独立证明超自然因果的盲测。

### 产权撤回（3臂，契约来源）

- 先有“The house belongs to Thomas Hayes.”，再有“The previous ownership claim has no support and is withdrawn.”，最后追加对更早事件的迟到抽取。
- 来源为 `memory-corrections.test.mjs`；the-haunting只是该测试的战役壳。
- 这是状态与有效记忆判断，不是新的产权情节，也不测试内核事务已正确执行。

### 椅子观察与挥击（2臂，契约来源）

- “我只看看那把椅子，不拿起来，也不攻击。”／“我拿起那把椅子，向对手挥过去。”
- 来源为 `object-usages-admission.test.mjs` 的原英文句与 take/swing 提案，中文是忠实改写。
- **Chair用法不在科比特作者图里，不把它装成内置剧情。** 判断选择成立也不宣称攻击命中。

## 验证范围

- 本地源文件存在时检查真实SHA、定位器和唯一引文；不是只校验一份自造答案的哈希。
- 检查成对输入、Choice预期闭包、材料引用、AND／OR允许组合和评估标签隔离。
- 候选池是有意固定的小集合，适合诊断机制；**不证明全书召回、实际回合表现或所有同类问题都已穷尽**。
- 这两书及历史题源均已参与设计，不是新书盲测。不同臂和共享同一神像／甲虫规则的题，不应拆开后冒充互不泄漏的独立测试集。
