# 谜之屋

官用规则测试模组。`scenario_id`: `mystery-house`

不是 Chaosium《鬼屋》翻版，也没有 `module-graph.json`（图谱 starter 仍锁在
`module-the-haunting`）。这是可 `quick_start` 的 IR 包，调查骨架改写成滨江柯宅，
每个地点都埋了 CoC7 规则图谱细钩。逻辑可以荒唐：房东霍承远会直接教法术。

## 开桌

`setup.quick_start` / `campaign.quick_start`，`scenario_id=mystery-house`。
不附带预生成调查员。

## 地点与细钩

| 场景 | 细钩 |
| --- | --- |
| 霍承远事务所 | 学法术、当场施法、手枪 |
| 晚报剪报库 | 架子砸伤 |
| 市立图书馆 | SAN 符文；Library Use + Spot Hidden 组合检定 |
| 市政档案厅 | 钉子轻伤；与老沈对立检定 |
| 滨江警署 | 运气/贿赂；指路诊所 |
| 巷口闲话 | SAN 故事；先裁定社交难度 |
| 马氏旧居 | SAN；通往疗养院 |
| 废教堂 | 眷族 SAN+战斗；卡住的门=孤注/运气；击退回复 SAN |
| 柯宅一楼 | 地板陷阱；战技夺刃 |
| 楼上 / 地下室 / 巢 | 原高潮：SAN、战斗、结局 |
| 后院追逐链 | 屏障 / 危险 / 逃脱 |
| 陈氏公寓 | 安全休息；结束本段 |
| 北区诊所 | 急救/医学/稳定/一周大伤口 |
| 疗养院探视房 | 治疗 / 洞察 / 现实检验 |

受伤、疯狂、due trigger 的数字仍要桌上用规则工具结算。`chase:conflict` 仍受内核限制。
