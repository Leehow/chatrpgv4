# Mystery House

Official rule-gym starter. `scenario_id`: `mystery-house`

Boston, 1920. Not a Chaosium reprint, and there is no `module-graph.json`
(graph starters still lock `module-the-haunting`). IR pack for `quick_start`.
Every lead site is stocked with CoC7 settle hooks. Crane will teach spells
on purpose.

## Start

`setup.quick_start` / `campaign.quick_start`, `scenario_id=mystery-house`.
No pregens.
