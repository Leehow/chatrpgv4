# voice-bench — the chat bench

A seeded scene for testing how NPCs talk (docs/specs/npc-voice-mask.md §4), not a scenario.
Tianjin, October 1926, a rainy night in a dockside teahouse: nine people of nine stations,
each holding one fragment of last night's sinking of the barge 福顺号. One start scene, one
dock to walk to, nine conversation clues, no beats and no threats. Unlisted, like
`mystery-house`; open it by id:

    uv run --frozen python tests/play/driver.py start --campaign voice-bench-1 --pregen shen-zhiwei --module voice-bench

`module-graph.json` is generated by `tests/play/fixtures/voice-bench/build.mjs`; edit the cast
there and re-run it, never the JSON by hand.
