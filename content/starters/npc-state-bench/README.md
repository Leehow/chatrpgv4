# npc-state-bench — the NPC state bench

A seeded scene for the host-settled NPC state (contract §259), not a scenario. A river town's
grain shop in October 1926: the keeper 钱老板 has a printed routine (the shop from 08:00 to 18:00,
a 40% chance of the teahouse back room in the evening and at night, else home), his brother
钱老二 is tied to him on the graph, and each knows one clue. Unlisted; open it by id:

    node tests/play/driver.ts start --campaign npc-state-bench-1 --pregen shen-zhiwei --module npc-state-bench

`module-graph.json` is generated by `tests/play/fixtures/npc-state-bench/build.mjs`; edit the cast
there and re-run it, never the JSON by hand.
