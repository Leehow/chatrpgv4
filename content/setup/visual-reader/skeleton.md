## Read phase: skeleton

For purpose skeleton, stop after a small source-grounded structure: module premise, authored opening alternatives and thin relevant destinations using the existing node/claim vocabulary. Read native navigation and only the contents, overview and entry evidence needed to identify these. An entrance is where players begin making active decisions. A teaser, flash-forward or read-aloud passage that rewinds to another start is an optional presentation technique on that start, not a separately playable entrance. Read the surrounding instructions rather than treating a section heading as proof of interactivity. Do not prepare NPC dossiers, numeric blocks, handout crops, full opening dialogue or later chapters. Set ready_nodes to an empty array, cite every node, mark important structure claims critical, and resolve only structure-level dependencies. Run the normal checker. The host will present alternative openings before requesting the selected opening's detailed material. This paragraph defines the whole scope for skeleton; the detailed preparation instructions below apply to opening/detail only.
