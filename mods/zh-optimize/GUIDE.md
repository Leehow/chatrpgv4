# 写一个语言优化包：以「中文优化」为例

这份说明给想为别的游玩语言做同类优化的人。它不是运行时文件，守秘人读不到它。

## 为什么要有语言优化包

模组、人物设定和规则大多用英文写成。守秘人用别的语言写正文和台词时，很容易把英文的句法和节奏原样带过去。中文里的表现是：一句一个句号、每句都有主语、书面词、抽象名词当主语。玩家读着像翻译腔。基底和叙述手艺包都不按语言写规则（游玩语言是开放的，基底不登记任何语言），所以某一种语言的地道说法，放在这个语言自己的包里。

## 包能用的四个接口（契约 §153、§165）

1. `play_languages`：声明本包服务哪些游玩语言的标签，例如 `["zh"]`。新建战役时，战役声明的 `play_language` 标签与之匹配（完全相同，或主语言子标签相同：`zh` 匹配 `zh-Hans`、`zh-Hant`），本包默认开启；不匹配就默认关闭。只看标签，不检测文本。
2. `brief`：每回合提醒，语言包各自上限 400 字节（UTF-8），不占所有默认包共用的 5000 字节。中文一个字 3 字节，大约 120 字，只放最要紧的几句。
3. `contributes.voice_lane_addendum`：接在口吻卡车道指令后面的附录。每个在场的人的口吻卡（mask 和三组示例问答）每回合都随胶囊到守秘人手里，守秘人照着它说话，所以示例写得地道，比多写几条规则更管用。需要 `requires` 里有 `npc.voice.language-addendum.v1`。
4. `contributes.speech_edit_lane`：台词润色车道的指令和示范（契约 §165）。每回合交付之后，宿主把这一回合 NPC 说的每句话、玩家的话和正文交给模型，按这份文件只改措辞（连接词、语气词、口语用词），事实一律不动；改好的句子先过结构检查和 Jev 的事实核对，再原地替换玩家卡片上的原句，守秘人和内核的记录不变。本包的文件是 owner 判过的 v2：按功能列的连接词与语气词，加 owner 亲手改的真实台词做示范。长短看情景：被威胁、打斗、慌乱、走投无路时，只是重复或装饰的句子可以去掉；闲聊时保持原长。需要 `requires` 里有 `speech.edit.lane.v1`；同一桌只能有一个包提供它，两个都开着时车道不跑。

完整指令（`instructions`，本包是 `agent.md`）在开局和重新装配时整份给守秘人；其余回合只给提醒。

## 怎么找本语言的问题

1. 先读真实输出，别先写规则。把几桌真桌的台词拿出来，挑出本语言读者觉得不像人话的句子。本包起点就是一句「进。只准看，不准撕、不准夹走。弄皱了算你的。」，owner 说「正常人哪有这么说话的」。
2. 追到源头。本包查到的源头是口吻卡：车道把模组的 clipped、short offers 直译成「说话短促」，示例问答写成一截一截的句号，守秘人照着模仿。改提示词、让同一个模型自己改写，都没有明显效果。
3. 查本语言的翻译研究，找「源语言干扰」的常见形态。中文参考：思果《翻译研究》（总原则：中国人会这样说吗）、余光中《怎样改进英式中文》（万能动词、及、介词、地、的、被动六类病）、英汉「形合 / 意合」对比（中文靠语序和事理，用逗号连成流水句）、汉语语气助词的功能（吧、呢、啊、嘛、了承载态度）。
4. 对其他语言，通常要回答这几个问题：
   - 英文的「短句、干脆」在本语言靠什么表达？（中文：语气词和用词，不是句号。）
   - 本语言的句子怎么连接？标点习惯和英文有什么不同？
   - 本语言的敬语、称呼、正式程度怎么分层？书面语和口语的界线在哪里？
   - 本语言口语里有哪些承载态度的小词？（日语的终助词、德语的情态小品词等。）
   - 本语言读者最常抱怨的翻译腔是什么样子？

## 怎么写

- 规则写成「怎么说」，配上成对的例子：一句翻译腔，一句地道说法，事实不变。例子只示范说法，要写明「不照抄内容」。
- 不写词表去判断或替换文本：那是开放的语义问题，写死的词表永远盖不全。例子可以有，检测和替换不可以有。
- 只改说法，不改内容：事实、数字、立场、谁知道什么，一律不动。脾气、粗话开关、口吻卡的归属仍由叙述手艺包管。
- 提醒写最要紧的一两条，完整道理放在 `agent.md`。

## 怎么验证

- 同一组预先写好的玩家输入，同一个守秘人模型，开一桌不装本包、一桌装本包，每桌 15 回合左右。
- 台词用成对比较：同一回合两桌的台词并排、左右随机，让不知道分组的读者选哪边更像真人一口气说出来的话。按段计数「拼凑台词」量不准，同一批段落两次能数出 3 和 0。
- 最后让本语言的母语玩家自己读几组并排的原文。评判标准在开桌之前写好，不许事后挑读法。
- 不擅自换模型。怀疑是模型的问题，先把理由和要试的模型列给 owner。
