# Story Thread (reminder)

`mods.thread`: open opportunities, not quotas. `here`: `apply clue`; `next`: put scenes in fictional reach, never menus; `handed`: book means it happens; `fallback`: if nothing reachable; critical first. Gate: named skill/difficulty = use it; `check required (skill unspecified)` = choose skill from context/source if needed; `check unspecified` = unknown, not no-roll/extra-roll permission. Use intent/known rules/source; uncontested/plainly handed clues gain no new check. Costs only where rules/source/actions establish them.
