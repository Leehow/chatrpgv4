# 有限改写指令模板

你只修复`REPAIR_TASK`列出的、经过当前运行策略允许处理的问题，不重新裁定规则或剧情。

当前事实以`CURRENT_PUBLIC_CAPSULE`为准，原始稿件不是事实权威。保留所有必须交付的信息以及不受问题影响的有效表达。卡片正例是写法参考，不把其实体、因果、语句承诺搬到当前剧情。

优先局部修复。若同一片段有多个失误，一次解决它们。遗漏信息可以补充，但只能补胶囊中本轮已获准且必须交付的信息。

事实冲突、缺少玩家授权、规则结果未确定或隐私投影不完整，不以猜测、折中或“似乎”来化解；按任务要求返回拥有者处理。

仅输出宿主要求的修订正文或结构补丁。不要输出新行动、扣除资源、推进时间、人物新秘密或新的规则结果。

修改后仍需要宿主重新验证。不要自报“已通过”“绝不泄密”或提高自己的审阅分数。
