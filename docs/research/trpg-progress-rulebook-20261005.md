## 核心结论

**日常行动不必掷骰。**规则把角色行动、玩家与 Keeper 的讨论视为游戏的重要组成部分；普通、无争议的日常事务直接处理即可，例如开车去历史协会。只有出现紧张、冲突或有意义的不确定性时才掷骰；“容易的任务”也不应浪费骰子。若需要掷骰，玩家先明确想达成的目标，成功即完成掷骰前已同意的目标，而不是自动扩大为玩家临场描述的一切结果。失败意味着该目标未达成，但失败的具体表现由情境决定，通常不应机械地立刻造成伤害或理智损失，也不等于“失败就是成功”。这套目标—结果关系是实际规则；如何描述后果、如何推动场面，则是 Keeper 的裁量建议。

**线索应区分必需与可错过。**若信息是推进剧情所必需，书中建议把它做成“obvious clue”：玩家无需掷骰即可得到。若线索只是有用、但找到或错过都能让游戏继续，则可做成“obscured clue”，用感知类技能处理；失败应让玩家知道玩家层面上似乎漏掉了某物，从而可忽略、基于直觉行动，或采取能正当化再次尝试的行动。书中特别反对把整个冒险押在一个可隐藏、可绕过的线索上；重要信息应能通过不同路径、不同形式获得。这里没有把“三条线索”或固定数量的线索奉为官方规则：原书说的是多种策略和多条可行获取方式。

**玩家目标与进展不是固定轨道。**线性场景可以作为新 Keeper 的起点，但书中明确承认玩家会追不同线索、提出预想外的调查方向；强行把他们拽回预写剧情，会使贡献显得无价值。非线性场景应准备地点、人物、关系、事件和背景，而不是预先写死故事与结局；玩家选择决定这些元素如何连接，未知结局可以真正出现。玩家走向 Keeper 未预料的路径不只是“容错”，而可能是最好的即兴部分。故不能把“成功”定义成回到唯一预设路线，也不能把固定回合/固定轮数当作本书的规则。

**节奏与过度谨慎。**Keeper 的建议是观察小组：若讨论重复、玩家无聊或完全卡住，应引入戏剧性、NPC 求助、行动压力，或提供 Idea roll；但若玩家对每个小动作都极度谨慎、长时间计划，且这可能源于先前 Keeper 过于严厉的游戏经验，则应稍微放宽，并在他们承担的风险合理时给予安抚，而不是简单施加更多压力或加快推进。书中没有规定固定时间、回合或“若干次搜索”上限。Pacing 是主持建议，不是把玩家选择替换成自动剧情的授权。

**Idea roll 是恢复调查方向的特殊机制。**它用于调查停滞、遗漏关键线索时；其目标始终是“让调查回到正轨”。最高 INT 的调查员掷 INT 对应的 Idea roll，难度取决于线索此前被提及的程度。关键点是：**无论成功还是失败，玩家都会得到该线索**；掷骰决定的是“如何得到”，不是“有没有线索”。成功时 Keeper 应把线索编入叙事、给出足够明确的方向；失败时，书中建议让调查员置身麻烦、浪费时间或在危急场景中意识到线索，因此代价/困境由结果决定，而不是失败后反复掷 INT 直到成功。

该段文字同时赋予 Keeper 一种异常宽的叙事权限：Idea roll 期间可推进时间、改变场景、把调查员放入合适情境；失败甚至可把任一调查员置于“thick of things”。这是规则书对 Keeper 的特定主持建议，不能悄悄移植为玩家代理权：在本研究所对应的软件 Keeper 中，仍须区分来源中的玩家目标、玩家选择、来源/收据约束，以及主持人建议。尤其不能据此声称产品已经支持完整的 Idea recovery 流程。

**没有东西时要给可靠的否定结果。**若场景没有线索，默认不应发起感知检定；若玩家主动要求搜索，Keeper 可以把目标限定为“寻找线索/某物”，成功时明确告知该线索或物品确实不在现场。这比模糊地说“那里什么也没有”更可靠，也避免玩家把一次不必要的失败误解为漏掉关键内容。它是对搜索结果的明确建模，不是保证每次请求都生成线索。
