## Confirmed current defect and chosen failure handling

The installed `pi-ai` 1.0.0 Responses parser creates a text slot, appends deltas,
and finalizes from `output_item.done`. It does not backfill message text from
`response.completed.output`. File SHA256:
`8744ad2ce9ce2512993360600760f5bcdbeb520d0a641c655b2a0b7cbe9db10a`.
Controlled SSE through that actual adapter reproduces zero normalized text for
terminal-only text and for empty item-done plus nonempty terminal text. These
events are explicitly controlled fixtures, never historical raw-stream evidence.

The first `message_end` handler now rejects a completed terminal message whose
observed text/refusal length is positive while normalized text is zero. It returns
`stopReason=error` with `responses_terminal_text_missing`, using Pi's existing
replacement port. The error reaches provider accounting, the infer result and
durable session history before tool proposals can execute. Inconsistent proposals
are removed; earlier canonical settlements are retained. No dependency, vendor
patch, phase guard, model setting, response budget or retry allowance changes.

This repairs explicit failure classification, not the adapter's text backfill.
Raw terminal text is not retained or published outside canonical narration. The
fixed message is not auto-retryable. Missing terminal observations and existing
parser errors remain distinct; genuinely empty completed responses keep their
single bounded turn-close repair. Partially nonempty normalization is outside
this narrowly scoped all-empty guard.

External cross-check: the official [Python Responses stream implementation](https://github.com/openai/openai-python/blob/main/src/openai/lib/streaming/responses/_responses.py)
uses the terminal response output for its completed result and errors if a final
completed response was not received. The official [Node stream implementation](https://github.com/openai/openai-node/blob/master/src/lib/responses/ResponseStream.ts)
separates raw event delivery from its accumulated final response, and can return an
incomplete snapshot after a clean end. They confirm that stream fragments and the
final result are distinct surfaces; their incomplete-stream semantics differ and
do not justify inventing the missing v32 payload or relaxing Pi's terminal guard.
