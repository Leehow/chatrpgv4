# ADR-0004 桌级世界线分支：宿主方法，不经守秘人 apply

2026-09-09。伴随契约 §29 与 `docs/specs/memory-line-panel.md`。

## 背景

§15 定下世界线操作是世界的改变，守秘人只能经 `apply` 效果发起（法则二），执行在回合提交之后。「记忆线」面板（§29）要让**玩家**点击任意历史节点开一条新线——那一刻没有守秘人回合可挂，也不该为一个界面操作造一个回合。

## 决定

桌级分支走宿主向 RPC `table.branch`，与建战役、开桌同级：操作者是桌子前的人，不是模型。实现复用 §15.9 的迁移机器（seal → 建分支 → 检出 → 注册表覆盖写回 → 重播骰子种子 → 重建检查点），失败即回滚；旧线的每个提交原样保留（证据永不删除）。守秘人经下一次胶囊的一次性 `branched` 节与 `worldlines` 节知晓换线，玩家在聊天流里经 `coc-mechanics` 分水岭条目看见分界。

## 否决的替代

- **宿主伪造一个 `apply fork` 回合**：把桌外操作伪装成模型行为，污染回合记录、收据统计与真桌 KPI，且违背「回合由守秘人关闭」的回合状态机。
- **前端直接操作 git**：违反 ADR-0001 的内核单一写者边界；锁、种子、检查点、注册表没有一处能由前端代劳。
- **连 Pi 会话一起回滚（彻底读档）**：另一个量级的改动，且与证据永久法冲突；守秘人上下文本是可丢弃缓存，真相在胶囊。若真桌证明「守秘人记得被放弃的未来」破坏体验，再单开切片（规格 D2）。
