# Triage Labels

技能用五个分诊角色说话；本仓库的工单是 Markdown 文件，标签就是文件开头 `Status:` 行的字符串。

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者还没评估                            |
| `needs-info`               | `needs-info`         | 等报告人补信息                            |
| `ready-for-agent`          | `ready-for-agent`    | 已完整规格化，可交给无人值守的 agent 做    |
| `ready-for-human`          | `ready-for-human`    | 需要人来做                                |
| `wontfix`                  | `wontfix`            | 不做                                      |
