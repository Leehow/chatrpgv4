## Acceptance criteria (original requirements retained)

- [ ] Entering a building or visiting a graph scene reveals only established visible geography. Room regions can be smaller than a scene and do not inherit disclosure merely from scene visits or a whole-asset player-safe tag.
- [ ] Support knowledge acquired without movement, such as looking into a room, and knowledge obtained from a plan. Hearing a location name or possessing a document does not reveal unrelated layout or undiscovered secrets.
- [x] The Keeper identifies semantic map/region names and an in-fiction basis. Existing admission checks the relevant action; deterministic code validates structure and authority but does not classify the player's meaning using keywords, regexes or language tables.
- [ ] A previously concealed source-backed area can become visible after its actual discovery, including when omitted from the investigator version. Different source variants require verified region correspondence rather than shared-pixel-coordinate assumptions.
- [ ] Visible geography excludes undiscovered annotations, secret doors/compartments and Keeper notes. Partial observation cannot reveal a whole room's secret content; retained layout is not live NPC position or current line of sight.
- [ ] A physical map handout retains its authored information and intentional mistakes. A map reference in the interface does not create a physical item or silently promote uncertain document content into authoritative geography.
- [ ] The kernel records disclosure and receipt atomically. Rejected or unsupported changes reveal nothing; a display failure leaves the correct knowledge transaction and last valid authorized view distinguishable.
- [ ] Exercise these behaviors through existing RPC and public image interfaces, then observe the real Keeper's disclosures during natural play, preserving source-to-region-to-receipt evidence and actual UI images.
