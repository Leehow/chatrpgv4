## 一句话

NPC 不再只做菜单上的事。模型先写一句这个人此刻做了什么，系统再把这句话绑到规则能结算的方式上。
- 在场的人被作用到、被点名，或者正在和调查员对话，每回合都会行动；
- 同一个目的不许换个说法反复说却不做（生成的行动和 KP 添的台词都受这条约束）；
- 没有事先准备的局面，掷一枚威胁骰：危险度越高，越容易出事，也越容易掏出出乎意料的东西。

## 做了什么（按机制）

- **处境包 → 生成 → 绑定 → 执行**（§143.1–§143.3）：
  - `npc.situation` 给出这个人此刻的处境，6 KB 预算；
  - `runtime/jev/npc-act.ts` 用快模型零工具补全，写出一句行动；
  - `npc.act.options` 列出规则能结算的方式，一次 Jev 批选方式和参数；
  - 书记员执行这一步，收据带 `intent.generated`。
- **谁在什么时候行动**：
  - 他自己的战斗回合；
  - 被作用到、被点名；
  - 在对话中（§143.20）：扫描只排在 KP 写回合的模型步之前（§143.25）；声明是战斗动作且还没结算时，扣住被指向的人（§143.25），等那一击落地后再轮到他（§143.28）。
- **说话对象**（§143.21、§143.23）：
  - 玩家原话只在“点名了别人”或“移动之前说的”时拿掉；
  - compile 能看到上一回合的交谈，用来读“你”指的是谁；
  - 没点名时，包里标明“这句话没点名说给谁”，由生成器自己判。
- **不重复**（§143.5、§143.14、§143.24、§143.29）：
  - 按目的判，不按字面或手上的动作判；
  - 重复一次就重问，第二次放弃这一行并丢弃这个行动；
  - KP 替 NPC 添的台词也过同一道闸，第一次交付打回，第二次放行；
  - 包里标出“他自己拿出来过的东西”。
- **威胁骰与意外**（§143.8、§143.19、§143.22、§143.26、§143.27）：
  - 四档：calm / tense / dangerous / lethal；
  - 对他的暴力（这回合挨打、上回合挨打、正在打架）归一组，只升一档；
  - 意外只能是桌上没人知道的东西，能按“同一类”对上规则书的记录，武器掏出来就能开火。
- **准入**：
  - KP 用人物卡代号点调查员也会复核；
  - compile 判“没有战斗动作”时，KP 替调查员出的拳直接拒（§143.18）；
  - 准入车道坏 JSON 重问一次（§143.15）。
- **其他**：逃跑的站位（§143.9）、追逐认 NPC 当猎物（§143.12/13）、正文标记闸与 line-2 §138 的分工（§143.10/17 的注）。

## 注意

- **改过号**：本分支的 §138/§139 在合 line-2 之前改成了 §142/§143（37b5b7d34）。旧提交信息和 scratchpad 里写的 §139.x，就是现在的 §143.x。
- **合并时的坑**：
  - 两边各自追加的代码块拼在一起时，冲突外面共享的那个收尾 `}` 只剩一个；
  - 自动合并会把两边各加的同名 import 都留下，导致扩展整个加载失败，表现是“Tool resolve not found”。
  - 合完先用 esbuild 或 import 检查一遍，再构建。
