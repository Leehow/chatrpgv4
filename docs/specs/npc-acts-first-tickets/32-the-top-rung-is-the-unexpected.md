# 32 — 顶档就是意想不到：出格、不重样、掏出来就能用

## 证据

造景探针（`lethal:severe`，gate-a T3–T8，3 轮 18 次）：18 次全是「藏着的一把左轮」，只变藏处与口径。真桌 tense 档的意外反而五花八门（广告、徽章、医生回信、协查便函）。用户要的是跑团的乐趣：裤裆里掏出火箭筒、躲进厕所掏出一把电锯。

## 用户的裁定（2026-09-26）

顶档（severe 的意外）不求合理，求意想不到：越没人猜得到越好，荒诞、不合年代、完全不成比例都欢迎，只要桌上能想象他此刻把它掏出来。低档的意外照旧是「身上或手边有、没人知道的东西」。

## Scope（全是数据与模型判断，不写清单、不写正则）

1. **许可句（数据）：** `npc-stakes.json` 的 `lines.severe_surprise`（各档）改写成邀请出格：不必合理、越出人意料越好、荒诞/不合年代/不成比例都可以，只要能想象得出此刻掏出来；`lines.surprise` 不动。`content/setup/npc-act.md` 的许可段补一句同义的话（顶档是为了桌上的乐趣）。
2. **不重样（结构）：** `npc.situation` 加 `table_brought_out`：这张桌上**所有人**已经掏出过的东西（工单 30 的 `brought_out` 标记与 `world.npc_weapons` 的来历），最近在前，封顶若干条，预算里先于 holdings 被裁。说明里一句：顶档的意外不要是这张桌上已经出现过的那一类东西。判「是不是同一类」交给生成器本身，不做代码比较。
3. **掏出来就能用（数据）：** 有 `produces` 的绑定（§143.19）价目表对意外不按模组年代过滤：同名记录优先模组年代，其余年代的记录也给（现代的 Chainsaw、M79 Grenade Launcher、Minigun……），于是出格的武器能对上规则书的数值（§143.22 按类别对）。非意外的路径（没有 `produces`）不受影响。
4. 契约：§143 末尾追加新小节（编号接当前末尾），§143.8 / §143.19 加带日期的注。
