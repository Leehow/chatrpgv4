## 超过一分钟的原因

**218.061 秒：前景来源准备与拒绝补救。** 主守秘人 7 次调用 95.989 秒；11 工具合计 114.584 秒。主要是第二次 apply 的 99.141 秒：并行准入墙钟 13.935 秒、前景 read-9 从 claim 到 accounting 69.817 秒（作者 47.466、独立复核墙钟 21.046）、后段 establish-review 15.039 秒。其附带叙述被 `needs/establish_thin` 拒绝，已提交 8 张状态收据，随后模型修正并 narrate 成功。前一次 apply 另有 `invalid_params/untold_name` 拒绝。没有网络重试。

**113.061 秒：上游生成错误。** 三次守秘人调用 9.090 / 61.242 / 17.956 秒；失败请求由服务端先发 SSE error、response.failed，明确记录 `Internal error during token generation`，code 为 null。本地 transport_error 在后，不能认定为宿主 60 秒超时。实际重试一次，声明退避 2 秒、观测间隔 2.229 秒；没有前景来源等待。另一个 0.587 秒错误属于被取消的准入短车道，不是第二次上游故障。服务端内部触发原因未知，未证明 payload 大是原因。

**80.958 秒：模型往返与建立场景审查。** 主守秘人三次 6.672 / 30.783 / 13.603 秒，合计 51.058 秒；4 工具 21.876 秒。首次 apply 已提交 7 张状态收据，其叙述被 `establish_thin` 拒绝，含 12.193 秒审查；随后 13.603 秒模型修正。没有网络重试或前景来源准备。不能把 30.783 秒全部叫思考时间，记录的 thinking 事件跨度只覆盖其中一段。

短车道已计入工具时间，作者/复核包含在材料准备时间，后台读取不再叠加到玩家墙钟。当前证据指向模型往返、前景读者/复核与拒绝补救，未显示 SQLite 操作是这些长回合的主要耗时。
