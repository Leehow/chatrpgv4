# 沉浸式建卡：方法

这份文档只写**方法**，不写实现。它从
`plugins/coc-keeper/rulesets/coc7/skills/coc-character/SKILL.md` 中抽出，原因
是引导路径将被重写（见
[pi-coc-onboarding-redesign.md](../specs/pi-coc-onboarding-redesign.md)），而这
套建卡手感是那条路径上**唯一值得原样带走的东西**。

新实现照这份文档做；不要照旧代码做。旧实现里与 `setup.chargen_run` /
`coc_chargen_delegate` 绑定的字段清单、骰子回执包、`input_mode` 取值属于**写入
契约**，不在本文档范围内，也不随引导重写而改变。

## 红线

**全程不向玩家提问数值。** 属性、技能点、现金、消费水平一律幕后派生。守秘人也
不得把现金/资产数字写进委托参数。玩家说的是人，不是数值。

## 一条完成路径，三种收尾

不存在「快速模式」与「详细模式」两条路。只有一条，按玩家给了多少来收尾。

**第一个问题只问：姓名 + 职业概念。** 不问别的。

- **空收尾** — 玩家给了姓名职业，并明确把其余交出（「其余全由你定」）。
  **不要再追问任何维度。** 直接语义补齐：年龄、3–6 条前六背景线索、一条
  **模组专属**的卷入方式、随身物、关键联系人、职业标签、母语。同一回合呈现完整
  草稿。玩家确认后才写卡（除非他同时说了「现在就写」）。
- **部分收尾** — 玩家给了其中一些。**最多 1–3 个入戏的问题，一次一个，只问还
  缺的那几条。** 如果玩家只给了姓名职业、又没有把其余交出，那一回合绝不写卡。
- **已给即锁定** — 玩家已经说过的任何事都是硬约束：不覆盖、不重问。

伤痕、恐惧与躁狂、秘典遭遇留给游玩，不在建卡里问。

## 模组感知的建议（必须做，不是可选）

用 player-safe 简报（时代、地点、前提）**主动提供**参数建议，用守秘人的口吻，
不是问卷：

- **语言**：开场实际需要的语言。1920 年代美国开场不能让调查员不会说英语。
- **职业**：贴合该时代与地点的营生。
- **随身物**：属于这张桌子的东西。

母语若不是模组工作语言（例如波士顿桌上说国语），必须把工作语言作为技能写进
去；只在散文里说「会英语」不会落账。技能值低于职业档（50%）意味着只能有限交
谈，不能独立查档、访谈、处理法律文书——把这个后果讲清楚，让玩家选择提高还是安
排翻译同伴。**玩家坚持低设定时，绝不静默覆盖。**

## 卷入方式必须挂在这本模组上

`scenario_bound` 要指向**这个模组的具体开场**，不能是「被卷入一件怪事」这种通
用句。玩家问怎么卷入时，**至少给一个已经挂在开场上的具体建议**（例：「Knott 的
委托信已经到了你手上，约你今晚去看宅子」），可以再给一个备选，但不要开成
「熟人介绍／登报／受托」的选择题。

## 命名工艺

名字要贴合 `era` 与场景的地点、文化，靠语义判断。

- 1920 年代波士顿桌用贴合时代的美国名；中文名只在虚构或背景支持时才用（例如
  唐人街移民）。
- **语言 ≠ 族裔**：`play_language` 是 zh-Hans 不代表角色是中国人。
- 玩家只给绰号（如「大手」）时，当绰号处理：在虚构里补一个时代与文化贴合的正
  式名，确认时让玩家改——**不要硬塞一个中国全名**。
- 外文名转 zh-Hans 用像样的译名，必要时括注读音。
- 避免套路名；单一文化设定也要在地域、阶层、方言上有变化，别一桌一个姓。

**锁名前自查**：这个名字贴合 era／地域／文化吗？我是不是因为桌面语言是中文就默
认了中国名？

名字由守秘人依据自己对时代、地点、文化的知识现造。**不许用固定名字池，不许注入
随机池代码，不许关键词/正则判定。** 这是语义手艺。

## player-safe 简报

campaign 有绑定模组时，在掷属性或选职业**之前**先给玩家看简报。它给的是气氛与
「什么样的人适合这张桌子」，不含守秘人内容。

把它当**素材**：用桌面语言把有用的部分口语化地讲出来，然后问下一个建卡问题。
**绝不把 Markdown 原文、标题、生成元数据或操作指令倒进桌面对话。**

## 引导闭环

上面这些（母语落到具体语种、模组化卷入、时代得体的职业与随身物）在**一开始就
作为建议告诉玩家**，不是做成表单。玩家描述里漏掉的，在最终草稿里用模组上下文
补齐并展示出来。玩家已经说过的仍然是硬约束。

## 写卡之后

把 `player_summary_zh` 与卡片「## 玩家摘要」的句子**逐字**呈现——每一个成功/失
败、每一个现金/资产/消费数字。不要改写、省略、反转判断，也不要说「以卡内为准」
就把摘要略过去。
